# xAgent v0.1.1

2026 年 10 月 23 日

本次更新改善会话恢复、模型配置和管理体验。

## 新增与改进

- 模型配置保存时自动测试连接，并显示测试结果；新模型的默认最大输出调整为 16K，可按需修改。
- 网络或模型服务暂时异常时自动等待重试，显示倒计时，并支持随时停止或继续。
- 加快登录后会话列表加载，改善长会话页面流畅度。
- 审批结果展示更清晰，触发器新增执行历史。
- 业务表格统一支持调节数据列宽，操作列保持固定；统一卡片和图标背景样式。

## 问题修复

- 修复重启或继续后会话状态显示不准确的问题。
- 修复部分提示残留、窄屏表格溢出和“到底部”按钮显示异常的问题。

## 升级提醒

- 升级前请备份配置和数据。
- 升级后，如已有模型未出现在选择列表中，请到模型管理页完成连接测试。测试失败的配置仍可保存，修复连接问题后再用于任务。
- 本次更新仅涉及服务端，桌面客户端、独立插件和运行时资源包沿用原有版本。

## 安装与下载

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

支持 Linux 和 macOS 的 AMD64、ARM64 平台。发布文件包括：

- `xagent-v0.1.1-linux-amd64.tar.gz`
- `xagent-v0.1.1-linux-arm64.tar.gz`
- `xagent-v0.1.1-darwin-amd64.tar.gz`
- `xagent-v0.1.1-darwin-arm64.tar.gz`
- `SHA256SUMS`、`BINARY_SHA256SUMS`、`release.json`
- `LICENSE`、`EULA.md`、`THIRD_PARTY_NOTICES.md`

下载附件后用 `shasum -a 256 -c SHA256SUMS` 校验；Linux 也可使用 `sha256sum -c SHA256SUMS`。每个平台包仅包含可执行程序、版本说明和授权文件，不包含源代码。
