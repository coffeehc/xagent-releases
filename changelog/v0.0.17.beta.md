# xAgent v0.0.17.beta

发布日期：2026 年 9 月 9 日。

本版本完善 AgentPlugin 工具卡展示与协议兼容，统一会话消息来源和协作语义，并增强模型流式调用恢复与失败诊断；同时发布六个官方 AgentPlugin，钉钉首次进入公开目录和四平台安装链路。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server，并可选择安装支持的 AgentPlugin。

## 主要更新

### AgentPlugin 工具卡

- AgentPlugin Card 可以为每个工具声明图标和安全摘要字段；xAgent 直接使用插件声明渲染工具卡，不再根据工具参数猜测展示内容。
- 展示 selector 只能读取当前工具公开 input/output schema 中已经声明的字段，并限制摘要数量、候选字段和分隔符长度。
- Browser Runtime 与微信、Telegram、飞书、Database、SSH、钉钉官方插件均补齐工具图标和关键参数摘要。

### 会话与协作

- 建立统一的 MessageContext 来源投影，覆盖 AgentPlugin、Trigger、跨会话消息和审批决定，时间线可以稳定展示真实消息来源。
- 删除独立的持久协作状态链，改由 `collaboration_request`、回复标记和 Session Prompt 驱动模型判断，避免状态与消息事实分叉。
- 修复空正文校验、公共通道来源伪造、AgentPlugin 精确回复和异步会话失败未反馈的问题。

### 模型可靠性与诊断

- Provider 流式读取在首个有效事件前发生可重试中断时会自动重新建立请求；已经产生有效输出后不会重放，避免重复内容。
- 模型工具调用格式无效时继续执行既有自动修正；多次修正仍失败后，用户会收到明确的可行动提示。
- 区分内容策略拒绝、模型输入不合法、Provider 调用失败和模型工具调用格式无效；管理员事件记录稳定错误码、阶段、校验原因和脱敏后的 Provider 响应。

### AgentPlugin 兼容性

- Card revision 使用插件返回的原始 Card 快照计算，旧 schema 归一化不再造成 health revision 误判。
- 数据平面协商支持按插件 Card 声明回退到协议 `4.3` 或 `4.0`。

## 升级注意事项

- 升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和已安装 AgentPlugin 的配置与数据目录。
- Server 与本次官方 AgentPlugin 版本应一起升级，以获得完整的工具卡展示和协议校验能力。

下载完整 Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```
