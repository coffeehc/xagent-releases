# xAgent v0.0.11.beta

发布日期：2026 年 8 月 19 日。

本版本完成 Connector 运行体系升级，正式加入 Database 与 SSH Connector Server，并让 Connector Skill、文件能力、认证和多资源路由使用统一协议边界。同时新增图片生成工具、会话临时工作状态，并收口 Skill 标识、模型配置与 Connector 管理体验。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server，并可选择安装支持的 Connector。

## 主要更新

### Connector 协议与运行时

- Connector 公共协议升级到 `4.3`。xAgent 同时兼容 `3.0`、`4.0`、`4.1` 和 `4.2` Connector，并在数据平面握手时协商实际版本。
- 删除 `target_type`。xAgent 只按 Connector Card、Profile、Tool、认证流程和 Channel 协议处理业务，不再按业务分类枚举限制 Connector 接入。
- 同一用户与同一 Connector Server 只建立一条真实 Connector Channel；多资源模式按 `resource_key` 路由业务 VChannel。
- Connector Card 声明的工具注册为全局 Runtime，模型可见性只由 Card 注册和真实运行时健康决定。
- 文件传输从 IM Profile 中拆分为独立的 `xagent.file.v1`。
- Connector Skill 支持 `/skill.json` 目录清单、revision 下载和本地目录原子替换；脚本文件会被忽略，旧版 `/skill.md` 保持兼容。
- Connector 与内置 Skill 使用稳定英文 ID，并通过 Skill Cards 提供中英文展示。

### Database 与 SSH Connector

- 首次正式发布 Database Connector Server，支持管理员配置多个 MySQL 和 PostgreSQL 目标，并提供有边界的 SQL 工具。
- 首次正式发布 SSH Connector Server，支持多个 SSH 目标、主机指纹校验、私钥目录、审计身份认证和 SSH/PTTY 交互式 shell。
- Database 与 SSH 的目标系统凭据、原生权限和执行事实均由 Connector Server 持有；xAgent 只保存 Channel 归属和路由信息。
- 两个 Connector 都支持配置动态加载，资源定义变化后自动重新校验。

### 图片生成、会话与 Skill

- 新增 `image_generate` 原生工具，支持 OpenAI Responses 图片工具或 Images API；生成结果校验后保存为不可变 Session 产物。
- 模型配置通过 `default_policy.image_generation` 显式启用图片生成，删除无实际决策价值的 `supports_streaming` 字段。
- 新增会话临时工作状态工具，用于长任务中的结构化短期执行状态。
- Connector 会话名称只显示 Connector 名称，不再追加动态连接数量。
- SSH access token 认证同时要求 principal，以便准确归属操作审计。

## 升级注意事项

- Connector Server 与 xAgent 必须分别升级。旧 Connector 可以通过兼容协议继续运行，但不会获得目录式 Skill 和文件 Profile 等 4.3 增量能力。
- SSH 安装后请在 Connector 配置目录创建 `keys` 目录并放入私钥，再配置目标、principal 和 access token。不要提交真实私钥、token 或运行时指纹。
- 升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包，以及 Connector 配置、状态目录和 SSH keys。
