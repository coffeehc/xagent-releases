# xAgent v0.0.7.beta

发布日期：2026 年 8 月 7 日。

本版本新增统一的 Local/S3 文件存储、实例共享目录与文件 ACL，加入图片 OCR 能力，并首次发布支持自动升级提示的 Desktop Client 0.0.1。同时优化同一用户轮次中的模型上下文稳定性和缓存 Token 统计。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server。

## 主要更新

- 新增统一 Local/S3 文件存储 Provider，支持 S3 兼容 endpoint、静态或默认链凭据、启用前读写测试，以及 Local 与 S3 之间的受管迁移。
- S3 内容增加本地读取缓存、大小与 SHA-256 校验；远端不可用时自动降级到本地，恢复后补传内容并切回 S3。
- 新增实例级 `share` 共享目录，支持目录和文件管理，以及按用户或用户组继承的只读 `R`、读写 `RW` 权限。
- 工作区文件树固定显示共享文件入口，并按当前用户 ACL 浏览、预览和下载已授权内容；深层授权只展示通往授权子树的目录。
- 文件访问统一使用 `workspace`、`upload`、`share` 虚拟路径 ACL；会话工具按用户与会话合并后的权限执行读写检查。
- 新增可配置 OCR 模型角色，为图片附件生成包含可见文字、必要视觉描述和主要语言的规范 Markdown 派生内容。
- OCR 结果绑定模型能力 revision，配置变化后按需重建；没有文本层的纯扫描 PDF 在本版本仍不支持。
- 用户轮次开始时的上下文与本轮记忆绑定到真实用户消息，工具循环的实时状态追加到请求尾部，减少稳定 Prompt 的无效变化。
- 统一 OpenAI、Anthropic 和 Gemini 缓存 Token 字段的上报语义，并纳入模型连通性测试产生的系统用量。
- 首次发布 Desktop Client 0.0.1，提供 macOS Apple Silicon 与 Windows AMD64 包；后续出现新版本时，左下角显示升级图标，确认后自动下载、校验、替换并重启。
- 修复 Session Timeline 历史字符串消息和思考块关注状态的 TypeScript 类型错误，恢复 WebUI 与 Desktop 的生产构建。

## 校验与升级

下载 Server Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。升级前请备份 xAgent 配置、数据库、工作区、共享目录和 Connector 状态。首次启用 S3 时，应先保存并测试配置，再执行 Provider 迁移。
