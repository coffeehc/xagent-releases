# xAgent v0.0.9.beta

发布日期：2026 年 8 月 10 日。

本版本将管理后台与用户端拆分为两个独立入口，统一 Web 与桌面端会话工作区，并补齐会话提示词的编辑和运行时覆盖能力。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server。

## 主要更新

### 管理后台与用户端

- 新增独立的 `/admin/login` 和 `/admin` 管理入口，管理菜单、路由保护、登录跳转和退出登录均在管理后台内闭环。
- `/app` 固定为用户端入口。管理员通过 `/app` 登录时与普通用户使用相同的会话和个人工作区，不再显示管理菜单。
- 用户端与管理后台不提供互相跳转入口；系统版本提示和升级入口仅在管理后台显示。
- 管理菜单采用更短的中英文名称，账号菜单只保留当前入口需要的操作。

### 会话工作区

- Web 与桌面端统一为左右结构，左侧显示 xAgent 标识和会话列表，右侧显示当前会话。
- 主会话固定在搜索框上方，子会话继续按最近活跃顺序展示。
- 会话区随可用空间按比例伸缩并整体居中，在超宽屏上不再固定为窄列。
- 空会话提示、消息区和输入区使用统一内容基准线，描述文本获得更合理的可读宽度。
- 工具栏移除内部 Session 标识，高级配置改为图标按钮；侧栏账号菜单提供个人设置和退出登录。

### 提示词与配置抽屉

- 中文界面中的 Agent Prompt 统一显示为“提示词”。即使当前内容为空，也会提供可编辑文本框。
- 提示词默认展开，至少显示十行，并根据抽屉剩余高度伸展；长内容在文本框内滚动，不会把“实际配置”推到页面外。
- 保存后的会话级提示词从下一轮立即生效，覆盖范围包括主会话、Connector 会话和普通子会话。
- 表单和配置类详情抽屉禁止点击遮罩关闭，防止误触丢失未保存内容；纯信息类抽屉仍可点击空白处关闭。

### 用量统计

- 用户端仪表盘收敛为“用量统计”，仅展示当前用户的 Token、模型调用和 Tool 调用数据。
- 模型用量明细默认直接展示，不再需要手动展开。
- 管理后台保留独立的全局和按用户用量统计。

### 稳定性与维护性

- 首次新增会话提示词时复用当前会话角色基线，确保提示词覆盖能形成有效 Current Role。
- 读取旧 MemoryPointer 数据时保持原始持久化结构，不因读取或列表查询改写 Memory 文件。
- 数据库连接检查、Schema 创建和结构升级统一在存储服务启动阶段完成。
- 清理未使用的领域模型、Provider 请求辅助函数、Tool/Connector Service 包装、本地 Go 缓存和过期生成文件。

## 升级注意事项

- 管理员书签和反向代理规则需要从旧的 `/app/admin/...` 更新为 `/admin/...`，管理登录页为 `/admin/login`。
- `/app` 现在直接进入用户会话工作区；个人用量统计位于 `/app/dashboard`。
- 升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和 Connector 状态。
- 本版本不改变现有账号角色或业务数据；管理员仍可作为普通用户从 `/app` 使用个人工作区。

## 校验与升级

下载 Server Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。升级前请备份 xAgent 配置、数据库、工作区、Memory、Skill、Tool 包和 Connector 状态。
