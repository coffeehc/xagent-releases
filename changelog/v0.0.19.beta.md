# xAgent v0.0.19.beta

发布日期：2026 年 9 月 14 日。

本版本增加受管理员策略控制的文件外链分享，完善公开预览、下载授权与访问审计，并改进会话中断、模型重连和 Runtime Assets 离线可用性。

## 主要更新

- 用户可以从文件预览、会话文件和 Workspace 文件菜单创建限时外链，并在“文件分享”页面查看、复制或撤销链接。
- 外部访问者无需登录即可查看带动态水印的公开预览；每个链接独立设置有效期和原文件下载权限，不支持永久链接。
- 分享次数和下载次数按文件聚合，详情中保留逐链接状态与逐次访问记录。
- “文件分享”列表统一使用通用表格并支持手动刷新；修复空列表及多文件列表被误判为请求失败的问题。
- 文件分享详情抽屉加宽，完整展示分享链接、下载权限和访问审计记录。
- 管理员可以关闭外链、限制为仅 xAgent 产物或允许所有受管文件，并统一限制最长有效期、下载能力和公开 Base URL。
- 文件分享默认关闭，管理员明确启用后用户才可创建外链。
- 模型重连与不同类型的运行错误使用更明确的会话状态；手工中断只终止当前 Agent 调用。
- 会话处理状态与服务端执行生命周期保持一致，排队中的用户指令以服务端事件为准。
- Runtime Assets catalog 增加本地持久化快照，远端临时不可用时可从快照或当前 ready 安装恢复展示。
- LibreOffice 文档转换固定使用不可变 Runtime Assets 安装目录。
- 本版本只更新 xAgent Server，官方 AgentPlugin 版本与制品保持不变。

## 安装与升级

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和已安装 AgentPlugin 的配置与数据目录。

本版本会初始化文件分享及访问审计所需的 SQLite 或 PostgreSQL 表结构；升级后仍需管理员主动开启文件外链策略。

## 校验

下载完整 Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。如果只下载一个平台包，请计算该文件的 SHA256，并与 `SHA256SUMS` 中的对应记录比较。
