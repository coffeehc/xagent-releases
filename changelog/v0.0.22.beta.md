# xAgent v0.0.22.beta

更新日期：2026 年 10 月 2 日。

本版本为单智能体周期长任务补齐工作记录、跨轮等待、外部结果接续和会话归档能力，并改善工具参数提示与失败恢复。

## 主要更新

- 工作记录与台账共用数据库存储，同一主题通过增量条目保存新变化，通过短摘要保存当前判断，分别保留和分页读取历史。
- 工作记录工具按单一动作拆分，支持调用去重、摘要版本检查及明确的条目覆盖位置；模型按需读取正文。
- 输入框下端提供工作记录弹窗，无记录时隐藏入口；弹窗支持当前记录、历史、摘要版本、过程条目及附件预览。
- 工作记录摘要、历史版本和增量正文中的附件与工作区链接可点击打开，正文与引用栏重复附件合并显示。
- 密钥管理升级为环境变量，支持不可变的加密模式、文本值、说明与使用注意事项；加密值只暴露占位符，非加密值按需读取。
- 未加密变量的名称包含 KEY、TOKEN 等敏感标识时，保存前提醒确认；并发元数据更新不会覆盖新值。
- 固定文本角色仅配置上下文与输出预算，推理强度、温度和 Provider 参数继承所选模型，加载与保存时清理旧角色请求参数。
- 同一定时任务上一轮未结束时不启动下一轮；支持显式登记等待与完成，无需强制创建 Plan/Task。
- 等待回复没有默认超时，等待期间拒绝无关输入；Plan/Task 的等待期限作为信号处理，不直接判断任务完成。
- 定时投递在忙碌顺延、失败、回写异常和服务重启后保留原输入身份及计划时间；旧回调不能提前消费修改后的计划。
- A2A 保留原行动与远端任务身份，支持原任务查询、效果未知状态、迟到结果及关联恢复，避免旧结果覆盖已确认终态或错误启动新一轮。
- 优化记录身份、版本、游标和可选参数提示；改善模型输出截断、工具协议残片和文本编辑错误的有界恢复。
- 会话支持归档与恢复。归档停止执行和相关调度，保留消息、记录、任务、等待及文件；恢复需要明确操作才会续跑。
- 归档会话不占授权额度，恢复时重新检查容量；默认会话查询及沙箱隐藏归档会话，查询归档历史需显式指定。
- 保留删除入口，主会话和 AgentPlugin 专属会话继续通过原管理入口维护。

## 安装与升级

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

升级前请备份配置、数据库、用户工作区、Memory、Skill、Tool 包和已安装 AgentPlugin 的配置与数据目录。当前源码数据库迁移版本为 39，既有密钥迁移为加密环境变量；归档会话不计入授权会话额度，恢复时重新检查容量。
