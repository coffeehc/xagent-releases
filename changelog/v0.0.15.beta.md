# xAgent v0.0.15.beta

发布日期：2026 年 9 月 6 日。

本版本完成 AgentCore 执行链路切换，收短 Session 派工和文档产物流程，并完善 Office 生成、预览、转换、Excel 工具与 Runtime Assets 自动更新能力。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server，并可选择安装支持的 Connector。

## 主要更新

### AgentCore 与 Session 执行

- Agent 循环、SessionContext、任务语义、编排、智能体定义、OCR、摘要、Memory 和图片生成等模型调用统一接入 AgentCore，并删除切换后遗留的旧执行与校验路径。
- Main Session 派工只完整传递用户目标、输入文件和明确约束，不再自行补充字体、版式、质量检查或工具链要求；执行细节由对应 Skill 和 Tool 负责。
- 文档创建、追加和格式转换在 Tool 成功后即可结束，不再默认执行开放式读取、校验、修复和重复导出。
- 完善审批恢复、历史 Tool 批次回放、会话产物投影、上下文压缩和运行状态同步。

### Office 文档与 PDF

- Word、PowerPoint 和 Excel 统一使用 xAgent 默认 Office 模板与品牌样式，删除旧的 `business`、`clean` 和 `formal` 模板分支。
- Word 封面与目录分页，表格正文继承模板正文字体；PowerPoint 统一品牌色、排版和图表样式。
- LibreOffice 作为独立 Runtime Assets Catalog 软件包提供，统一支持 Word、PowerPoint 和 Excel 的 PDF 转换以及 Excel 重算保存。
- 完善 PDF、PPTX、DOCX、Excel 和 Mermaid 的前端预览路由与类型识别，并区分 Mermaid 的交互预览与导出渲染。

### Excel 与文件搜索

- 原生 Excel Tool 覆盖工作簿创建、结构检查、区域读写、追加、表格、图表、重算和 PDF 导出。
- Excel 附件不再预先转换并内联整份文本；模型按需要调用 Excel Tool 读取指定范围。
- 单个文本文件内搜索使用 `fs_search_in_text`；跨文件检索使用独立索引 Tool，并限定在当前 Session 可访问的文件范围。

### Runtime Assets

- xAgent 启动后自动同步 Catalog，并自动下载、安装和更新全部缺失或过期软件包。
- 软件包完成下载、校验、解包、初始化和探测后再原子切换 `current`；失败时继续保留上一套可用安装。
- 管理后台继续保留手工同步与单软件包升级入口，并展示安装阶段、失败原因和版本状态。

### 前端与管理界面

- Session 页面复用消息、Tool 历史、附件、状态和列表组件，减少重复渲染与大组件更新范围。
- 管理后台的数据表格、空状态、筛选、查询和操作布局统一复用公共组件。
- 修复智能体、Skill 和 Tool 卡片被错误包入单个网格项的问题，管理后台与用户设置中的卡片列表恢复按响应式列布局展示。
- 优化 Token 图表、WorkGroup 编排、Connector、备份、用户、Tool、Skill、模型与系统监控页面的渲染和状态更新。
- 执行环境页面移除重复的 Catalog 标题与平台版本说明。

## 升级注意事项

- 升级前请备份配置、数据库、用户工作区、Memory、Skill、Tool 包和 Connector 状态。
- Office 模板 Catalog 已统一为 `document.office-default-template`；旧 `document.office-templates` 包及 `business`、`clean`、`formal` 模板不再使用。
- Runtime Assets 会在启动后自动对齐当前 Catalog；更新失败时继续使用上一套 `current`，可在管理后台查看失败原因并手工重试。
- xAgent Server 与 Connector Server 独立发布和升级；Connector 推荐版本以公开 Catalog 为准。

```bash
shasum -a 256 -c SHA256SUMS
```
