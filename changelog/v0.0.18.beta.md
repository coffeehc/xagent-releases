# xAgent v0.0.18.beta

发布日期：2026 年 9 月 11 日。

本版本统一模型请求、Tool Schema 和 usage 的处理边界，改进模型配置与上下文用量展示，并修复空上传目录的读取问题。

## 主要更新

- OpenAI 兼容 Provider 可以从 `/api/models` 读取模型候选项，也可继续手工输入真实模型名。
- 模型编辑器提供上下文上限、最大输出、推理强度、思考开关、思考 token 和思考温度等常用字段，并继续保留 Raw JSON 扩展参数。
- 会话用量优先使用 Provider 实测值，明确区分未返回 usage 与返回 0，缺失时才回退到估算。
- Tool Schema 严格模式兼容、流式响应聚合与工具参数回正统一由 AgentCore 处理，减少重复转换引起的协议差异。
- Tool Card 取消固定 4 个摘要片段的限制，同时保留 selector 校验与最终文本长度限制。
- 空的用户上传目录会正常显示空列表，不再提示 `uploads 不存在`。
- Provider 原始 `finish_reason` 保持不变，不再为诊断附加完整模型 Profile 和请求参数。
- 本版本只更新 xAgent Server，官方 AgentPlugin 版本与制品保持不变。

## 安装与升级

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和已安装 AgentPlugin 的配置与数据目录。
