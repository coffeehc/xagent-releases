# xAgent v0.0.10.beta

发布日期：2026 年 8 月 16 日。

本版本重点完善任务理解、能力准备和跨会话协作，并补齐平台能力自知、项目化会话导航、上下文观察、文件交付、Skill 展示和管理员恢复能力。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server。

## 主要更新

### 任务理解与能力准备

- 子会话会先判断新消息与当前阶段目标及会话总目标的关系；任务延续时保持当前环境，目标变化时再调整 Skill、Tool 和长期记忆。
- 能力检索从任务目标中分别提炼英文 Skill、Tool 和 Memory 检索短语，减少普通分词过细造成的错误匹配；独立 Tool 也可以直接进入候选范围。
- System Introduction 概述 xAgent 发现 Skill 与 Tool、使用长期记忆和凭据引用、连接外部系统，以及接收外部入口或定时触发信号等平台能力；本轮实际可用能力仍以运行时事实和权限为准。
- 会话界面显示任务语义理解、要点提取、能力查找、任务编排和环境应用状态。
- Tool 可用时由模型根据任务自行决定是否调用，不再强制每轮必须调用；没有 Tool 时明确禁用 Tool 调用。

### 会话、项目与协作

- 会话侧栏按会话、项目、团队和 Connector 分组，支持创建项目及项目内会话。
- 子会话使用明确的会话目标和首条任务消息，附件随任务传递，执行结果会回到准确的来源会话。
- 跨会话协作请求持久保存，页面刷新或服务恢复后仍能维持正确的等待和回复关系。
- 执行中可以把过大的计划步骤拆成连续检查点，并保留已有进度。

### Skill、上下文与文件

- Skill 支持按用户语言展示名称、描述和图标，并在管理页和会话能力选择器中保持一致。
- 高级配置展示当前会话实际加载的 Skill 与 Tool；会话工具栏新增只读上下文缓存快照。
- Markdown 文件支持渲染预览与源码切换，电子表格可以切换工作表。
- Workspace 文件新增稳定的独立下载页面，支持直接链接、失败重试和再次下载。

### 用户偏好与管理员恢复

- 回复语言与界面语言统一为确定的中文或英文设置；回复详细程度和工作流风格继续由个人偏好控制。
- 格式化用户数据会同时清理长期记忆、记忆摘要和后台提取状态，但保留账号、Skill、密钥、Connector、模型配置和 Token 统计。
- 新增服务器本机管理员密码恢复命令，重置成功后旧登录状态会全部失效。

### 稳定性

- 修正 OpenAI 及兼容 Provider 在输出上限截断 Tool 参数时可能误执行空参数调用的问题。
- 统一流式与非流式 Tool 参数校验、结束原因和历史回放，减少重复 Tool 调用和无可见结果。
- 收口会话回复、Prompt 装配、文件访问和存储兼容路径，减少重复解释和执行。

## 升级注意事项

- 会话协作相关存储结构会自动升级，无需手工迁移数据库。
- “格式化用户数据”的范围已经扩大到长期记忆和后台记忆任务，执行前请重新确认清理内容。
- 管理员无法登录时，可停止服务后在服务器本机执行 `xagent admin reset-password --username <管理员用户名> --config <config.yml 路径>`。
- 升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和 Connector 状态。

下载 Server Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```
