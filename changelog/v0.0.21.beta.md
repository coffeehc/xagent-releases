# xAgent v0.0.21.beta

更新日期：2026 年 9 月 22 日。

本版本收紧模型配置和结构化输出契约，增强长会话压缩恢复，并完成公共 Skill 逐项制品协议与管理界面的收口。

## 主要更新

- 固定任务角色改用稳定的 Model Profile ID 引用模型配置；旧的模型名配置会在启动时迁移，无法解析时明确报错。
- Agent Definition Builder、任务能力编排、Task Semantics、OCR、Summary、Memory 和 Context Compression 统一使用严格 JSON 与业务 Schema 校验，拒绝重复键、额外文本、多段输出和非法字段。
- 结构化输出重试只反馈最新的字段级要求，不回放无效模型原文。
- 上下文压缩使用 90% 请求预算线；超长历史和 active turn 可分批摘要，全部成功后再一次性推进持久化边界。
- 模型达到上下文或输出上限时缩小摘要 source 后重试；未形成净压缩的候选不推进游标，也不阻断其它恢复路径。
- 公共 Skill catalog 升级为 v2，每个 Skill 使用独立不可变 ZIP 和 `skill.json`；不再生成整包制品或执行启动迁移。
- Skill 安装状态直接按当前加载的来源路径和版本投影，不再保存第二份安装记录。
- Agent Role 管理按 Model Profile ID 选择模型；工作编排编辑器可保留当前目录中已不可选但仍被引用的 Skill。
- 会话停止执行后，旧 running 轮次不再继续计时；会话列表使用稳定固定宽度，缩略导航更紧凑。
- 本版本只更新 xAgent Server，官方 AgentPlugin 版本和制品保持不变。

## 安装与升级

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和已安装 AgentPlugin 的配置与数据目录。

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。如果只下载一个平台包，请计算该文件的 SHA256，并与 `SHA256SUMS` 中的对应记录比较。
