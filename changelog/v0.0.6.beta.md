# xAgent v0.0.6.beta

发布日期：2026 年 8 月 1 日。

本版本重点完善附件读取、文档生成、模型配置、子会话协作和系统升级流程。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent。

## 主要更新

- 统一会话附件和工作区文件的接收流程，格式、大小和内容解析全部通过后才会完成上传。
- 支持 DOCX、可提取文本的 PDF、PPTX、XLSX、CSV、TSV、静态 HTML、Markdown、常见文本与代码文件，以及 PNG、JPEG、WebP 图片。
- Word 和 HTML 保留标题、段落、强调、列表、链接和表格结构；PDF、表格和演示文稿保留页面、工作表和幻灯片定位。
- 长文档自动生成结构化定位索引，模型可按需读取相关区段，不再一次性占用大量上下文。
- 修复工作区展示路径与真实文件身份不一致，以及中文和空格文件名下载乱码的问题。
- 提升 OpenAI、Anthropic 和 Gemini 模型配置兼容性、配置生效速度与请求缓存稳定性。
- 优化子会话初始化、能力装配和协作回复，减少参数缺失、重复执行和重复发送结果。
- 新增 Word 模板、共享文档字体和 DOCX 渲染验证能力。
- 控制台支持发起系统升级；受支持的托管安装会自动切换版本，并在健康检查失败时回滚。
- 移除废弃的“外接系统”入口，统一管理端 API 路径，并清理未使用的前后端代码。
- 完善用户数据格式化后的会话、附件、工作区和触发器清理。

- Linux AMD64
- Linux ARM64
- macOS AMD64
- macOS ARM64

## 发布文件

- `xagent-v0.0.6.beta-linux-amd64.tar.gz`
- `xagent-v0.0.6.beta-linux-arm64.tar.gz`
- `xagent-v0.0.6.beta-darwin-amd64.tar.gz`

- `release.json`

每个平台包只包含 xAgent 可执行文件、README、版本元数据和授权文件，不包含源代码。

## 校验

下载 Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。升级前请备份 xAgent 配置、数据库、工作区和 Connector 状态。
