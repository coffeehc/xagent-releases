# xAgent v0.1.0

更新日期：2026 年 10 月 18 日。

0.1.0 更新会话与管理界面，完善虚拟团队协作、归档和执行恢复，并加固认证与密钥边界。

## 主要更新

- 全站接入 XUI 4.2.18 正式组件，采用森林绿配色，统一列表、表格、卡片、表单及弹层。
- 表格操作保持透明背景，悬停只强调前景；危险操作保留独立颜色，带背景的纯图标控件采用圆形。
- 优化会话索引、耗时、工具调用、任务进度和审批提示，分别调整会话与管理侧栏的宽度。
- 支持虚拟团队创建、专用经理、成员会话树、岗位复用、经理委托与所有者指导，共享团队资料目录。
- 团队解散整体归档并保留成员关系；新增长期闲置会话自动归档，改善归档分页及只读资料查看。
- 统一会话输入批次和运行态恢复，完善团队派工中断、协作回放和消息接续。
- Web 与桌面使用统一 Cookie 会话链路，完善初始化、退出和新文档加载的生命周期处理。
- 密钥占位符只在允许的请求执行边界解析，文件、消息和持久化内容保留占位符。
- 升级 MCP SDK，加固连接复用、取消和失效恢复；改善 HTTP 首字节等待和流式响应处理。
- 优化首屏按需加载、静态资源压缩、结构化记忆详情、审批策略即时保存及异常记录管理。

## 安装与升级

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

升级前备份配置、数据库、用户工作区、Memory、Skill、Tool 包及 AgentPlugin 配置与状态。归档会话的恢复与继续执行使用明确入口；独立 AgentPlugin、桌面客户端及运行时资源包沿用各自版本目录。

## 校验与验证范围

下载全部附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 也可使用 `sha256sum -c SHA256SUMS`。单独下载某个平台包时，与清单中对应的 SHA256 比较。

本次没有重跑全量测试。四平台构建、包及二进制校验、安装器 mock 与公开下载完整性分别核对；不将这些检查等同于四个平台的完整业务验收。
