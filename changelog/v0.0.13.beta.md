# xAgent v0.0.13.beta

发布日期：2026 年 8 月 29 日。

本版本完善原生文件与文档处理、统一 CLI 和 Tool 的 workspace 路径契约，并将免费版调整为无证书直接生效的固定权益模型。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server，并可选择安装支持的 Connector。

## 主要更新

### 原生文件与 Tool 运行时

- 新增原生 HTTP 二进制下载、图片转换，以及更完整的 Word 文档读取、检查和更新流程。
- CLI 默认工作目录统一为当前 Session 的规范 workspace；模型可以直接使用相对路径，不再依赖 `$XAGENT_WORKSPACE` 前缀。
- ToolService 在执行前统一回正 workspace 路径参数，并对原生 Tool、MCP Tool 和 Connector Tool 使用一致的治理事实。
- 字体、运行时资产和执行环境使用统一就绪检查；缺少依赖时会在调用前给出明确阻断原因。
- HTTP 首字节等待、沙箱失败和 Tool 输出分类进一步收口，减少可恢复问题产生的平台异常噪音。

### 会话与用量界面

- 删除已由自动同步和重连恢复覆盖的 `/refresh_messages` 命令；消息加载失败界面仍保留内部刷新能力。
- Token 用量图表统一坐标轴与提示值格式，大数值使用紧凑显示。

### 免费版与企业授权

- 未安装外部授权证书时直接进入免费版，不再内置免费版证书或有效期。
- 免费版固定限制为 2 个用户、30 个会话、1 个 WorkGroup、5 个 Connector VChannel 和 5 个定时任务。
- 历史 v2 `free` 或 v1 `temporary` 证书会在启动时删除，并回退为无证书免费版。
- License Server 只签发企业版证书；历史签发记录仍可查看，但不再提供免费版签发。

## 升级注意事项

- 使用历史免费版证书的环境升级后会自动删除该证书，并按新的无证书免费版额度运行。
- 企业版证书仍保持原有签名、设备绑定、有效期和数量权益校验。
- 升级前请备份配置、数据库、用户工作区、Memory、Skill、Tool 包和 Connector 状态。
- Connector Server 与 xAgent Server 独立发布和升级；Connector 推荐版本以公开 catalog 为准。

## 校验

下载完整 Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。如果只下载一个平台包，请计算该文件的 SHA256，并与 `SHA256SUMS` 中对应的一行比较。
