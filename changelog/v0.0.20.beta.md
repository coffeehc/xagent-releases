# xAgent v0.0.20.beta

发布日期：2026 年 9 月 17 日。

本版本修复进程沙箱与工作区产物的执行问题，统一 Office 文档字体处理，并改进 PowerPoint 演示文稿的内容规划。Office 工具授权方式不变。

## 主要更新

- 修复进程沙箱运行时目录挂载、写目录隔离、隐藏挂载和工作目录问题。
- 修复进程工具生成的文件未正确提交到工作区的问题；会话草稿在沙箱中保持可见。
- 统一 Word、PowerPoint 文档及 PDF 预览的字体与缺字回退策略。
- PowerPoint 演示文稿生成器先规划受众问题和信息顺序，再选择视觉表达；新增产品方案、技术架构、项目进展、数据经营分析等场景参考，并扩展提案与市场研究参考。
- 新的视觉编排参考帮助将流程、架构、图表和比较映射到适合的幻灯片版式。
- 本版本只更新 xAgent Server，官方 AgentPlugin 版本和制品保持不变。

## 安装与升级

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和已安装 AgentPlugin 的配置与数据目录。

## 校验

下载完整 Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。如果只下载一个平台包，请计算该文件的 SHA256，并与 `SHA256SUMS` 中的对应记录比较。
