# xAgent v0.0.8.beta

发布日期：2026 年 8 月 9 日。

本版本新增在线增量备份与灾难恢复，重构 S3/WebDAV 云存储和公共目录接入，并支持直接从工作区选择会话附件。同时完善 Skill 与 Connector 能力展示、生产环境能力边界和本地存储自动清理。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server。

## 主要更新

- 新增在线备份与恢复管理，支持 S3、兼容 S3 和 WebDAV 备份仓库，以及手动备份、定时备份、完整快照和保留策略。
- 备份内容离开本机前完成加密；恢复支持在线下载与校验、停机目录切换、继续未完成恢复和失败回滚。
- 新增可离线保管的 `recovery.yml`，在原 xAgent 数据库不可用时仍可配合兼容版本的 Server 完成灾难恢复。
- 新增 S3/WebDAV 云存储接入管理。已启用的接入会按独立前缀显示在公共目录中，并继续使用用户和用户组 ACL。
- 授权用户可以浏览、预览和下载远端内容；管理员可以直接在接入目录中创建子目录和上传文件。
- 会话输入框新增“工作区文件”附件入口，可以从当前可见的工作区、公共目录或云存储中选择文件发送给 Agent。
- Skill 列表、搜索和 Agent 运行时能力按用户回复语言投影，Skill 名称在管理界面、会话和运行时保持一致。
- Connector Card 使用 Connector 服务声明的真实版本，并校验关联 Skill 标识。
- 生产模式隐藏开发期 Tool 管理入口，但不影响会话和 Agent 选用 Tool、审批策略及个人 MCP 配置。
- 新增按磁盘空间和 inode 水位触发的后台清理，只处理过期暂存、死信、终态诊断、会话临时数据、过期运行版本和无业务引用文件，不按年龄删除正式用户数据。

## 升级注意事项

- 从 `0.0.7.beta` 升级时，如果正式文件存储正在使用 S3，xAgent 会先校验旧目录归属和文件完整性，再把正式对象迁回本地。旧 S3 不可访问或校验失败时，启动会停止并保留原配置。
- 正式文件存储从本版本开始固定使用本地存储；S3 和 WebDAV 作为云存储接入映射到公共目录。
- 初始化备份仓库后，请立即下载并离线保管最新的 `recovery.yml`。该文件包含访问和解密备份所需的敏感信息。
- 在线备份不包含公共目录接入背后的第三方云存储内容，请使用对应存储服务自己的备份策略保护这些数据。

## 校验与升级

下载 Server Release 附件后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

Linux 可以使用 `sha256sum -c SHA256SUMS`。升级前请备份 xAgent 配置、数据库、工作区、Memory、Skill、Tool 包和 Connector 状态。
