# xAgent v0.0.12.beta

发布日期：2026 年 8 月 26 日。

本次同版本更新补齐 Memory 生命周期准入与分页管理、按模型预算自动压缩上下文、并发 Tool 调用和文件引用回退，并重新构建、覆盖发布四个平台的 xAgent Server 制品。

## 安装

Linux 和 macOS 使用同一个安装命令：

```bash
curl -fsSL https://downloads.xagent.xiagaogao.com/scripts/install.sh | bash
```

安装器会自动识别操作系统和 CPU 架构，下载并校验对应发布包，安装或升级 xAgent Server，并可选择安装支持的 Connector。版本号相同时，安装器会比较当前平台的二进制摘要并识别本次新构建。

## 主要更新

### 会话运行时与上下文

- 消息激活、会话协作、恢复和回复流程统一由 Brain 与 SessionEngine 管理，删除旧 SessionEvent 旁路、重复状态和兼容空壳。
- 上下文预算按当前模型实际生效的上下文窗口、最大输出和提示词开销动态计算；压缩摘要、近期消息和本轮输入使用同一套预算与缓存事实。
- 上下文压缩只由运行时按预算自动触发，不再提供容易与执行状态冲突的 `/compress` 手工命令；`/clear-history` 继续用于明确清空历史。
- 会话处于压缩中时，信息面板持续优先展示当前压缩状态，不再被较早的 Tool、模型或连接提示遮住。

### Memory 管理与长期准入

- 用户菜单和工作台提供“我的记忆”，可查看、手工添加和删除当前账号的长期记忆。
- 记忆列表使用数据库分页，可按关键字、类型、范围和来源筛选并选择每页条数；列表优先展示原始证据，完整结构可在 RAW 详情中检查。
- 后台提取先区分长期记忆、仅当前会话有效、拒绝和需要复核；问句、假设、未接受方案、确认话术、临时任务状态和敏感信息不会写入长期记忆。
- 只有纠正、混合证据、仅助手证据或疑似与既有记忆近义的候选才触发条件式语义复核；复核不能自动改写和替代既有事实。
- 提取分段预算跟随实际 Memory 模型上下文窗口，不再使用与模型无关的固定上限。

### Tool 调用与模型流式响应

- 同一轮多个 Tool 调用可在受控并发范围内执行；其中一个调用等待审批或继续时，已经完成的同批调用会先形成稳定历史。
- Tool 卡片在模型开始生成调用时立即出现，并明确区分“正在接收参数”和“正在执行”；达到模型输出上限的残缺参数不会进入真实执行。
- 限制兼容 Provider 在 Tool 调用生成期间连续输出空行造成的消息区域膨胀，同时保留后续正常正文和思考内容。
- 模型用量只归属到一轮 Tool 调用批次中的最终稳定结果，审批恢复、失败和并发执行使用同一套统计事实。

### 平台异常、数据与迁移

- 管理后台提供可开关的平台错误采集、聚合详情、样本查看、单项删除和历史清理。
- 工具参数、用户输入、模型驱动的 Tool 失败、业务重试和主动取消不再作为系统错误重复记录；真实基础设施故障仍保留为平台异常。
- 用户数据表能力并入统一 xAgentDB 存储服务；启动时迁移旧用户数据库，并在提交前检查表名、列定义和数据冲突。

### Connector、本地执行与文件

- Connector 连接描述增加结构化目标和运行状态；SSH 与 Database Connector 按用户实际授权资源展示目标。
- 继续支持 Connector Protocol `4.3`、多资源路由、目录式 Connector Skill 和独立文件传输 Profile。
- macOS 将 execution lease 和用户 Python 依赖移出 workspace 隐藏目录；Linux 修复只读上传挂载并显式移除全部 sandbox capability。
- workspace 文件引用复制增加非安全 HTTP 兼容路径，并保证连续复制不同文件时使用各自稳定的 `file_ref`。
- 读取、转换和写入已有文件的 Tool 可同时接收 `path` 与 `file_ref`：优先使用可访问路径，路径不可用时按稳定文件引用回退。

## 升级注意事项

- Connector Server 与 xAgent Server 独立发布和升级；Connector 推荐版本以公开 catalog 为准。
- macOS 和 Linux 会在首次启动时迁移旧执行运行时目录。迁移保留 Python 依赖，但会删除已经失效的临时 execution lease。
- 本次为同版本覆盖发布。安装器会继续比较当前平台二进制摘要，发现新构建后执行替换，并在覆盖前保留旧二进制用于回滚。
- 升级前请备份 xAgent 配置、数据库、用户工作区、Memory、Skill、Tool 包和 Connector 状态。
